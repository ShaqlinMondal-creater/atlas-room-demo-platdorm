# Test Now (`TEST5501`)

Remote MCQ exam desk for Atlas Room.

## Access code

**`TEST5501`**

## What it includes

- Start screen
- **100** sample MCQs (A–D)
- Timer (60 minutes)
- Question map + mark for review
- Score screen (correct / wrong / skipped)
- Answer review + retake

## Preview

1. `npm run dev`
2. Open **Test Now** and enter `TEST5501`
3. Or: `http://127.0.0.1:5173/templates/TEST5501/index.html?desk=1`
